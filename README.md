# 简视频

使用 HTML、CSS、JavaScript 编写的五平台影视聚合应用。统一展示腾讯视频、爱奇艺、优酷、芒果 TV、咪咕视频的公开推荐与搜索结果，在应用内打开官方登录和播放器。

仅提供 Android 端，使用 Kotlin 容器和系统 WebView。界面沿用简直播的蓝色、圆角卡片及底部导航，支持本机收藏和深浅主题。

## 使用

从 [GitHub Releases](https://github.com/kanxi12138/Simple-videos/releases) 下载正式发布的 APK；尚未发布正式版本时可按下文自行构建。当前版本为 `1.0.21`，构建的安装包统一输出到项目根目录，安装脚本也从该目录读取安装包。浏览与收藏无需登录，播放前必须确认对应平台已登录。在官网完成登录后，点击工具栏的“完成登录，继续”。待确认状态不会放行播放。

搜索结果分平台展示，官网安全验证会独立提示；点击“打开官网”在原搜索页面完成验证，再点击“完成验证，重试”。某个平台失败不影响其他平台。公开页面提供的数据在本机按每页 24 条展示，官网有下一页链接时继续加载。

首页启动时先展示上次成功获取的本机首屏缓存，再更新官网内容。手动刷新保留当前卡片，逐平台标记更新状态和上次获取时间；更新失败时保留旧内容并提示重试，官网明确返回空结果时显示空状态。重启后的旧缓存不开放分页，首屏更新成功后恢复。全屏播放仅使用官网原有控件，简视频统一控件整条隐藏，可以通过已识别的官网退出按钮或 Android 系统返回键退出全屏。普通播放页的统一控件及普通页面主导航不变。

官网登录会话保留在 WebView 自有存储中；登录确认后先完成 Cookie 落盘再恢复播放。账号检查与推荐获取分开，同一进程内最多复用 5 分钟的已确认状态且要求登录 Cookie 指纹不变。重启后仍复用官网会话，但需重新确认状态；上次确认时间只用于显示“上次已登录，待确认”，不会放行播放。官网过期、退出或撤销的会话仍需重新登录，不修改 Cookie 有效期，也不另存密码或 Token。

播放默认进入统一页面，提供播放、暂停、进度、全屏和官网真实清晰度、选集入口。播放器仍为系统 WebView 中的官网引擎，不提取视频直链。点击“官网操作”可在应用内使用完整官网的登录、验证、会员购买、弹幕与其他功能，再点击“返回播放”回到统一页面。读取不到的控件会明确提示，不能保证所有官网页面均支持统一控制。

内核支持与账号权益决定具体内容能否播放。实际登录、会员点播与直播验收已按用户要求延后，现有包不代表全片库播放兼容已获确认。

## 开发与构建

需要 Node.js、Windows PowerShell 7、JDK 17 或更新版本、Android SDK 36。默认 SDK 路径为 `%LOCALAPPDATA%/Android/Sdk`。

```powershell
npm.cmd run check
npm.cmd run build:android
pwsh -NoProfile -File scripts/install-android.ps1
```

配置 `android/local.properties` 中的 `sdk.dir` 后可以使用 Gradle 构建。Android 构建脚本在 `.local/signing` 生成独立 RSA 签名，密码由当前 Windows 账户的 DPAPI 加密保存，构建时通过环境变量传入。请备份该签名与账户恢复材料，丢失后无法以相同证书更新应用。签名文件、密码、设备资料与构建产物不进入源代码。

如需跳过 lint，可使用 `pwsh -NoProfile -File scripts/build-android.ps1 -SkipLint`。默认构建仍保留 Gradle 的 lint 流程。

安装脚本检查包名、版本与已安装 APK 的签名，签名相同才执行保留数据的更新；存在多台设备时通过 `-Serial` 指定目标。不匹配时停止，不卸载或清空已有应用。

## 应用更新与发布

设置 → 关于简视频 → 检查更新，手动查询公开仓库 `https://github.com/kanxi12138/Simple-videos` 的最新正式 Release；不会自动联网检查，也不检查草稿、预发布版本或普通 Git 标签。发现新版后可在应用内选择、下载 APK，下载校验完成后点击“安装更新”。首次安装需在 Android 系统设置中允许简视频安装应用，返回后再次点击安装；最终安装由系统确认，取消后可重试。

后续发布请使用 `1.0.22` 或 `v1.0.22` 这样的三段数字标签，并附上同版本原独立签名 APK，优先命名为 `Simple-videos-1.0.22.apk`。APK 的包名必须保留 `com.simplevideos.app`，版本名称对应 Release 标签，版本码高于已安装版本；上传代码到仓库根目录或只创建 Git 标签不会触发更新。多份 APK 附件需用户选择，没有 APK 时只提示缺失，不下载源码 ZIP。草稿、预发布及低于当前应用的版本不提供更新安装。

下载仅使用指定仓库的 GitHub 官方附件地址及官方重定向，保存到应用私有缓存；连接超时 10 秒、读取超时 30 秒、总时限 5 分钟，最大 200 MiB。核对声明大小、GitHub 可用的 SHA-256 digest、APK 包名、版本和签名。下载中切页可恢复状态；进程存活时后台可继续，进程终止后需重新检查下载，不提供断点续传。系统安装入口打开不代表升级成功。源码、账户 Cookie 和签名私钥不会发送到更新接口。

本次 1.0.21 仅完成相关语法检查及必要的 Release 编译、签名核对、保留数据安装、版本和交付资源核对。仓库当前没有正式 Release，在线检查、附件下载、安装来源授权及应用内升级均未经本次实机功能验收。

## 代码结构

- `web/`：Android WebView 界面、本机收藏、主题与容器通信。
- `shared/`：平台配置、公开页面提取规则及五平台官网播放器控件适配。
- `android/`：本地资源加载、与官网分离的 WebView、全屏与返回键。
- `scripts/`：构建、签名、安装和相关检查。

本地前端不直接访问官网接口，容器加载实际网页后提取公开元数据。官方登录会话留在容器原生 Cookie 存储中，收藏仅存影片元数据。远程网页没有 Android 原生桥接。

## 验证与限制

DRM 与播放能力由系统 WebView 和官网决定，会员点播与直播尚未完成账号验收。统一页仅隐藏已识别的独立暂停广告弹层，保留片头、插播、画面内广告、试看和权益提示；播放器之外的官网操作通过完整官网入口完成。清晰度和选集仅映射可读取的官网控件，不生成虚构选项。跨域播放器无法读取状态时保留官网操作。官网改版、验证或客户端限制可能影响提取和播放，失败会明确显示，不返回伪造内容。

当前功能行为未通过完整实机验收；语法检查、编译或安装成功不代表五平台功能均已通过。历史本地验收与诊断记录不随源码公开。
